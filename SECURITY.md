# Security Policy

WI Pass is intended to become a password and digital identity manager. Security issues may expose highly sensitive user data and must be handled responsibly.

## Current status

This repository is currently in planning stage and does not yet provide a production password manager. Do not submit real credentials, vault exports, recovery phrases, or personal secrets in issues or pull requests.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities publicly. Use GitHub's private vulnerability reporting feature if enabled for this repository, or contact the repository maintainers through a verified private channel.

Include a clear impact description and reproducible steps using synthetic data only. Do not access, modify, or retain other people's data.

## Security expectations

- Follow the WI Arch security baseline.
- Security-sensitive changes require threat-model review and tests.
- No claims of end-to-end encryption, zero-knowledge security, independent audit, or production readiness until independently supported by implementation and evidence.
- Never commit secrets or real vault data.
